* **Official Documentation:** ALWAYS base HTML structures and CSS classes on the official GOV.BR Design System documentation: https://www.gov.br/ds/home.
* **Strict Implementation:** Do not invent classes. Use standard `br-*` classes (e.g., `br-button`, `br-input`, `br-card`, `br-table`).
* **No Bootstrap Conflicts:** Avoid raw Bootstrap classes unless wrapped in GOV.BR utilities.
* **Accessibility:** Ensure ARIA labels and roles match the guidelines found at https://www.gov.br/ds/home.
* **Components:** When asked for a UI element (like a card or menu), look up the specific HTML structure in the GOV.BR DS specifications.
