# Product Overview

## IDS Joomla EB - Template Padrão Digital de Governo para Joomla

This is a comprehensive Joomla extension package designed specifically for Brazilian Army (Exército Brasileiro) websites, implementing the Brazilian Government Digital Standard (Padrão Digital de Governo).

### Core Purpose

- Provides a complete Joomla template and extension suite for government websites
- Implements Brazilian government design standards from https://www.gov.br/ds/
- Enables Brazilian Army units to create standardized, compliant websites

### Package Contents

- **1 Template**: IDS Gov - Exército Brasileiro (govbr-ds)
- **2 Components**: Aniversariantes (birthday management), PagTesouro (payment system)
- **6 Modules**: Anniversary section, image popup, Instagram feed, custom links, read more button, YouTube video carousel

### Target Users

- Brazilian Army units and organizations
- Government agencies requiring digital standard compliance
- Joomla developers working on government projects

### Key Features

- Full Joomla 5.4+ and 6.x compatibility
- Automatic update system via GitHub
- Semantic versioning
- Modern PHP 8.3+ architecture
- Portuguese and English language support

### Current Version

Version 2.0.0 (October 2025) - Major release with Joomla 6 compatibility
